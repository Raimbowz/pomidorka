# FocusBot - Telegram-бот для управления сессиями фокусировки

Telegram-бот, который помогает управлять рабочими и учебными сессиями с использованием техники Pomodoro и альтернативных методик тайм-менеджмента.

## Возможности

### Фокус-сессии
- Несколько готовых методик: Pomodoro, 52/17, Ultradian, Short Focus
- Создание пользовательских методик
- Управление сессиями: старт, пауза, возобновление, остановка
- Уведомления о смене фаз работы и отдыха
- Предупреждения перед окончанием фазы
- Статистика по сессиям (за день, неделю, месяц)
- Восстановление сессий после перезапуска сервера

### Пользовательские напоминания
- Создание персонализированных напоминаний (например, "Выпить таблетку", "Позвонить врачу")
- Настройка времени и дней недели для каждого напоминания
- Опциональное подтверждение выполнения с кнопками действий
- Три пресета действий: ✅ Выполнить, ⏰ Перенести, ❌ Отменить
- Возможность отложить напоминание на 10/30/60/120 минут
- Статистика по выполнению напоминаний
- Автоматическое восстановление напоминаний после перезапуска

### Интерфейс
- Интерактивный интерфейс с кнопками
- Пошаговый мастер создания напоминаний
- Удобный выбор дней недели через inline-клавиатуру

## Технологии

- NestJS - фреймворк для Node.js
- TypeScript
- PostgreSQL - база данных
- TypeORM - ORM для работы с БД
- Redis - для кэша и очередей
- BullMQ - система очередей для таймеров
- Telegraf - библиотека для Telegram Bot API
- Docker Compose - для локального развертывания

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd pomidorka
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Заполните следующие переменные:

- `TELEGRAM_BOT_TOKEN` - токен вашего Telegram бота (получите у [@BotFather](https://t.me/BotFather))
- Остальные параметры можно оставить по умолчанию для локальной разработки

### 4. Запуск PostgreSQL и Redis

```bash
docker-compose up -d
```

Это запустит PostgreSQL и Redis в Docker контейнерах.

### 5. Запуск приложения

Для разработки:
```bash
npm run start:dev
```

Для production:
```bash
npm run build
npm run start:prod
```

## Команды бота

### Фокус-сессии

- `/start` - начало работы с ботом, регистрация
- `/start_session` - начать новую сессию фокусировки
- `/pause` - поставить сессию на паузу
- `/resume` - возобновить приостановленную сессию
- `/stop` - остановить текущую сессию
- `/stats` - показать статистику по сессиям
- `/methods` - выбрать методику работы

### Напоминания

- `/reminders` - показать список всех напоминаний
- `/add_reminder` - создать новое напоминание (интерактивный процесс)
- `/toggle_reminder <ID>` - включить/выключить напоминание
- `/delete_reminder <ID>` - удалить напоминание
- `/reminder_stats` - статистика по выполнению напоминаний

### Другое

- `/settings` - настройки бота
- `/help` - справка по командам

### Интерактивные кнопки

Бот также поддерживает работу через кнопки:
- 🚀 Старт - начать сессию
- ⏸ Пауза - пауза
- ▶️ Возобновить - возобновить
- ⏹ Стоп - остановить
- 📊 Статистика - показать статистику
- ⚙️ Настройки - настройки
- 📋 Методики - выбор методики

## Методики работы

### Встроенные методики

1. **Pomodoro (25/5 × 4)**
   - Работа: 25 минут
   - Короткий перерыв: 5 минут
   - Длинный перерыв: 15 минут (после 4 циклов)

2. **52/17**
   - Работа: 52 минуты
   - Перерыв: 17 минут

3. **Ultradian**
   - Работа: 90 минут
   - Перерыв: 20 минут

4. **Short Focus**
   - Работа: 15 минут
   - Короткий перерыв: 3 минуты
   - Длинный перерыв: 10 минут (после 3 циклов)

## Использование напоминаний

### Создание напоминания

1. Отправьте команду `/add_reminder`
2. Следуйте пошаговым инструкциям:
   - Введите название (например, "Выпить таблетку")
   - Введите описание или пропустите (`-`)
   - Укажите время в формате HH:MM (например, `09:00`)
   - Выберите дни недели через inline-клавиатуру
   - Выберите, нужно ли подтверждение выполнения

### Взаимодействие с напоминаниями

Когда приходит напоминание с подтверждением, вы увидите три кнопки:

- **✅ Выполнить** - отметить задачу как выполненную
- **⏰ Перенести** - отложить напоминание на 10/30/60/120 минут
- **❌ Отменить** - отменить текущее напоминание

### Управление напоминаниями

- Просмотр списка: `/reminders`
- Отключить/включить: `/toggle_reminder 1` (где 1 - ID напоминания)
- Удалить: `/delete_reminder 1`
- Статистика: `/reminder_stats`

## Архитектура

### Модули

- **UserModule** - управление пользователями
- **MethodModule** - методики фокусировки
- **SessionModule** - управление сессиями
- **StatsModule** - статистика по сессиям
- **ReminderModule** - система напоминаний
- **TelegramModule** - интеграция с Telegram
- **TimerModule** - система таймеров для сессий
- **NotificationModule** - уведомления

### База данных

Схема базы данных включает следующие таблицы:

**Фокус-сессии:**
- `users` - пользователи
- `methods` - методики работы
- `sessions` - сессии фокусировки
- `session_events` - события сессий
- `statistics` - агрегированная статистика

**Напоминания:**
- `reminders` - пользовательские напоминания
- `reminder_logs` - история выполнения напоминаний
