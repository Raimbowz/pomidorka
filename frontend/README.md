# FocusBot Frontend - Конструктор напоминаний

Веб-интерфейс для управления напоминаниями FocusBot, построенный на SvelteKit 5 и Tailwind CSS.

## Технологии

- **SvelteKit 5** - современный фреймворк для Svelte
- **Svelte 5** - с новым синтаксисом runes ($state, $props)
- **Tailwind CSS v4** - утилитарный CSS фреймворк
- **TypeScript** - строгая типизация
- **lucide-svelte** - иконки
- **bits-ui** - примитивные компоненты для accessibility

## Возможности

- 📋 **Список напоминаний** - просмотр всех активных и неактивных напоминаний
- ➕ **Конструктор** - создание новых напоминаний через удобную форму
- ⏰ **Настройка времени** - выбор времени и дней недели
- ✅ **Подтверждения** - опция требования подтверждения выполнения
- 🔄 **Управление** - включение/отключение и удаление напоминаний
- 🎨 **Темная тема** - автоматическая поддержка светлой и темной темы
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## Установка и запуск

### Предварительные требования

- Node.js 18+
- Backend API FocusBot должен быть запущен на `http://localhost:3000`

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для production

```bash
npm run build
```

### Предпросмотр production сборки

```bash
npm run preview
```

## Основные компоненты

### Главная страница (`+page.svelte`)

Содержит:
- Список всех напоминаний с фильтрацией по статусу
- Форму создания нового напоминания
- Кнопки управления (включить/выключить, удалить)

### API клиент (`lib/api.ts`)

Класс `ReminderAPI` с методами:
- `getAll(userId)` - получить все напоминания пользователя
- `create(dto)` - создать новое напоминание
- `update(id, dto)` - обновить напоминание
- `delete(id)` - удалить напоминание
- `toggle(id)` - переключить статус активности
- `getStats(userId)` - получить статистику

## Использование

### 1. Просмотр напоминаний

При открытии страницы автоматически загружаются все напоминания текущего пользователя (userId = 1 для демо).

### 2. Создание напоминания

1. Нажмите кнопку "Создать"
2. Заполните форму:
   - Название (обязательно)
   - Описание (опционально)
   - Время (обязательно, формат HH:mm)
   - Дни недели (обязательно, выберите хотя бы один)
   - Подтверждение выполнения (опционально)
3. Нажмите "Создать"

### 3. Управление напоминаниями

- **Включить/Выключить** - кнопка с иконкой ⚡
- **Удалить** - кнопка с иконкой 🗑️

## Настройка

### Изменение адреса API

Откройте `src/lib/api.ts` и измените константу `API_BASE`:

```typescript
const API_BASE = 'http://your-api-url.com/api';
```

### Изменение userId

В файле `src/routes/+page.svelte` измените:

```typescript
const userId = 1; // Замените на нужный ID
```

В production версии userId должен приходить из системы аутентификации.

## Интеграция с Backend

Frontend взаимодействует с REST API endpoints:

- `GET /api/reminders/user/:userId` - список напоминаний
- `POST /api/reminders` - создание напоминания
- `PUT /api/reminders/:id` - обновление напоминания
- `DELETE /api/reminders/:id` - удаление напоминания
- `POST /api/reminders/:id/toggle` - переключение статуса
- `GET /api/reminders/user/:userId/stats` - статистика
