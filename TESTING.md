# Инструкции по тестированию FocusBot

## Успешная компиляция

Проект успешно скомпилирован! Все TypeScript ошибки исправлены.

```bash
npm run build
# ✓ Компиляция завершена успешно
```

## Предварительные требования

1. **PostgreSQL** - база данных для хранения сессий и статистики
2. **Redis** - для очередей задач (BullMQ)
3. **Telegram Bot Token** - получите у [@BotFather](https://t.me/BotFather)

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install --legacy-peer-deps
```

### 2. Настройка окружения

Скопируйте `.env.example` в `.env` и укажите токен бота:

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
DB_HOST=localhost
DB_PORT=5432
REDIS_HOST=localhost
REDIS_PORT=6379
```

### 3. Запуск инфраструктуры

Если у вас установлен Docker:

```bash
docker-compose up -d
```

Или установите PostgreSQL и Redis вручную.

### 4. Запуск приложения

Режим разработки:
```bash
npm run start:dev
```

Production режим:
```bash
npm run build
npm run start:prod
```

## Тестирование функционала

### Базовый сценарий

1. **Регистрация**
   - Отправьте `/start` боту в Telegram
   - Бот автоматически создаст профиль с методикой Pomodoro

2. **Запуск сессии**
   - Нажмите кнопку "🚀 Старт" или отправьте `/start_session`
   - Бот начнет сессию 25 минут работы

3. **Управление сессией**
   - `⏸ Пауза` - приостановить сессию
   - `▶️ Возобновить` - продолжить с того же места
   - `⏹ Стоп` - прервать сессию

4. **Статистика**
   - Нажмите "📊 Статистика"
   - Выберите период (сегодня/неделя/месяц)

5. **Смена методики**
   - Нажмите "📋 Методики"
   - Выберите одну из готовых (Pomodoro, 52/17, Ultradian, Short Focus)

### Проверка автоматических уведомлений

Бот будет отправлять уведомления:
- При завершении рабочей фазы
- При начале перерыва
- За 1-2 минуты до окончания (предупреждение)
- По завершении всей сессии с итоговым отчетом

### Проверка восстановления после перезапуска

1. Запустите сессию
2. Перезапустите бота (Ctrl+C и снова `npm run start:dev`)
3. Активная сессия должна продолжиться с того же места

## Проверка компонентов

### База данных

```bash
# Подключитесь к PostgreSQL
psql -h localhost -U focusbot -d focusbot

# Проверьте таблицы
\dt

# Должны быть созданы:
# - users
# - methods
# - sessions
# - session_events
# - statistics
```

### Redis

```bash
# Проверьте подключение к Redis
redis-cli ping
# Должно вернуть: PONG
```

### BullMQ очереди

Очередь `timers` отвечает за таймеры сессий и автоматические уведомления.

## Известные ограничения

1. **Docker недоступен** в тестовом окружении
   - Нужно запустить PostgreSQL и Redis вручную или на хостинге

2. **Telegram Bot Token**
   - Требуется реальный токен для полного тестирования
   - Без токена бот не сможет отправлять сообщения

3. **Тесты**
   - Юнит-тесты пока не реализованы
   - Можно добавить тесты с помощью Jest
